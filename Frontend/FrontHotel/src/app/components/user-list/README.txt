Layout y Encabezado:

.container: Envoltorio principal centrado y con ancho máximo definido.

.header-section: Sección flexible que alinea el título de la vista y el botón de acción principal.

.divider: Línea horizontal divisoria con estilo traslúcido.

Alertas:

.alert: Base para bloques de mensajes del sistema (carga, error e información).

.alert-info / .alert-danger / .alert-warning: Variantes de color para estado informativo, error o advertencia vacía.

Tabla de Datos:

.table-wrapper: Contenedor responsivo con bordes redondeados y sombra para la tabla.

.table: Estructura tabular limpia con tipografía optimizada e interlineado cómodo.

.table-row-clickable: Fila interactiva con efecto de resaltado (hover) e indicación de cursor para apertura de detalles.

Avatares:

.avatar-sm: Miniatura circular de perfil para cada fila de la tabla.

.avatar-lg: Foto de perfil destacada en tamaño grande para la ficha modal.

Modal Flotante (Ficha de Detalle):

.modal-backdrop: Fondo oscuro superpuesto con efecto de desenfoque (blur) que cubre la pantalla al abrir el modal.

.modal-card: Tarjeta central flotante con efecto glassmorphism que contiene la ficha completa del usuario.

.btn-close: Botón circular en la esquina superior derecha del modal para cerrar la vista de detalle.

.modal-header-profile: Cabecera centrada del modal con avatar grande, nombre y username del usuario.

.detail-grid: Cuadrícula responsiva que organiza la información del usuario en pares clave-valor.

.detail-item / .detail-label / .detail-value: Estructura tipográfica para etiquetas y valores individuales dentro de la ficha.

.modal-actions: Sección inferior contenedora de botones de edición y eliminación.

Insignias y Botones:

.badge / .badge-secondary / .badge-success / .badge-danger: Etiquetas pequeñas para representar roles y estados de cuenta (Activo/Inactivo).

.btn-primary: Botón principal de acción.

.btn-warning: Botón de acción secundaria/edición en tono ámbar.

.btn-danger: Botón de acción destructiva/eliminación en tono rojo.
