🎨 Guía de Estilos y Clases (README)
1. Variables Globales (:root)
Tipografía y Escala:

--font-family: Fuente base del sistema para toda la aplicación.

--font-size-xs: Tamaño pequeño (~13px) ideal para subtítulos, etiquetas y botones secundarios.

--font-size-sm: Tamaño medio-pequeño (~14px) usado en campos de entrada y botones principales.

--font-size-md: Tamaño base del sistema (~16px).

--font-size-lg: Tamaño grande (~24px) destinado a títulos principales (<h2>).

--font-size-title-fluid: Tamaño de título adaptable mediante clamp() para pantallas responsivas.

Colores y Fondos:

--color-primary: Color de acento principal (Indigo).

--color-primary-hover: Color de texto o acento al pasar el cursor.

--color-text-main: Color principal para textos y títulos claros.

--color-text-muted: Color secundario/atenuado para subtítulos e iconos.

--bg-main / --bg-gradient-*: Color y degradados de fondo para la pantalla completa.

--bg-secondary: Fondo traslúcido para contenedores con efecto glassmorphism.

--bg-input-icon: Fondo oscuro para los inputs y sus iconos.

--bg-btn-secondary / --hover: Estados de fondo para el botón de retorno.

Bordes, Efectos y Radios:

--border-*: Bordes sutiles y semitransparentes para tarjetas, inputs y botones.

--backdrop-blur: Efecto de desenfoque de fondo (glassmorphism).

--shadow-main: Sombra principal para dar profundidad a la tarjeta.

--radius-*: Niveles de bordes redondeados (sm, md, lg) para mantener consistencia.
